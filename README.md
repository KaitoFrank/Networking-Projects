# VLAN Network Lab — Router on a Stick

## Overview
A self-designed network built on Cisco Packet Tracer consisting of 
4 VLANs, 2 switches, 1 router and 8 PCs with full inter-VLAN routing.

## Technologies Used
- Cisco Packet Tracer
- VLANs (VLAN 10, 11, 12, 13)
- 802.1Q Trunking
- Router on a Stick (ROAS)
- Subnetting (/26)

## What I Learned
- How frames and packets move across a VLAN separated network
- ARP process in detail
- CEF and adjacency tables
- Troubleshooting trunk configurations
